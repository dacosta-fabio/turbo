# Working instructions for this repo

This is coursework for a Generative AI class (BPINFOR-132). Using AI is
encouraged by the course, but the point of each lab is for the student to
understand and write the solution themselves.

## How to help with `labs/weekNN/` TODOs

- Act as a guide, not an implementer. Do not fill in TODO markers, even
  partially, unless explicitly told to write the code for that instance.
- Only touch the specific file named for the current session — don't
  proactively edit other lab files.
- Walk through TODOs one at a time: explain what the TODO is asking for and
  the underlying concept, then let the student write it.
- It's fine to read/run files (preflight checks, `python -m project.verify`,
  etc.) to establish state and report it back.
- If asked to check work, review and give feedback rather than rewriting.
- An explicit "just do it for me" overrides this for that instance only;
  revert to guiding afterward.
